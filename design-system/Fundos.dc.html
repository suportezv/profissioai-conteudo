03 · Fundos
Aurora, o palco de tudo
Recriação em CSS dos 14 fundos oficiais do Drive. Manchas enormes, blur alto, drift lento, muito espaço negativo.
Aurora quente
#FDA4F5 + #FACD7C + #A5C2FE. Padrão para motion com UI clara.
Aurora fria
#81C3F0 + #A289F2 + toque #FACD7C. Variação para alternar entre posts.
Dark com glow
#07060B com glows do site. Para peças sem UI (a UI do app é clara).
Blur 120px ou mais
A mancha nunca vira forma. Se dá para desenhar o contorno, falta blur.
Drift contínuo e lento
O fundo respira o vídeo inteiro, quase imperceptível. Nunca para.
Grão 2 a 3%
Textura de filme sutil por cima, tira o aspecto de gradiente digital.
Espaço negativo
O fundo é palco, não protagonista. Um elemento por vez sobre ele.
